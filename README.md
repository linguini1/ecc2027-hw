# Hardware Experiments for "Kron-Reduced Connectivity Control for an Aerial Relay Network with Moving Ground Agents"

Contains videos of the hardware experiments conducted for "Kron-Reduced
Connectivity Control for an Aerial Relay Network with Moving Ground Agents",
submitted to ECC 2027.

* ``n3m3_live_localization-comp.mp4``: Control law executed in real-time with feedback from localization
* ``n3m3_replay-comp.mp4``: Control law executed based only on simulated agent positions, as a replay

Both experiments use 3 Crazyflies as UAV base-station agents, and 3 Limobots as
ground agents.
